# Gallop v0.1.0

Gallop's first public version implements persistent AI tutor state through a
local-first Markdown knowledge layer, deliberate practice through an external
DeepTutor adapter, structured practice protocols, conservative mastery tracking,
safe writeback, and isolated integration testing.

## Highlights

- Tutor → Knowledge → Practice → Mastery → Knowledge data flow
- user-owned Markdown/Obsidian source of truth
- structured session, manifest, result, and mastery schemas
- hint-aware mastery safety rules
- no-agent training configuration
- deterministic public demo with 7 questions, a fictional 5/7 result, and 1 → 2 mastery

## Limitations

Embedding-based semantic retrieval is not enabled by default. Tutor sync,
practice generation, mastery evaluation, and Markdown writeback work without it.
This is an early open-source release, not a production-ready stable release.
