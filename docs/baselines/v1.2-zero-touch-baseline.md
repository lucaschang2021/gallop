## Authority invariants

The baseline freezes the following semantics:

- Journal commit is authoritative for durable events.
- Tutor assessment is candidate evidence, not mastery authority.
- Human/authority confirmation is distinct from Tutor judgment.
- Target capability never raises current capability.
- Assistance cannot masquerade as independence.
- AI-generated code cannot count as independent coding evidence.
- Obsidian/Reader edits cannot directly promote mastery.
- Synthetic fixtures remain outside learner authority state.
- Four subject-bound Tutors share one Gallop system while preserving subject isolation.

## Recovery invariants

- stable event IDs provide exact-retry idempotency;
- same ID with different normalized content conflicts;
- incremental checkpoints survive process interruption;
- session restore uses Journal state rather than old transcript access;
- projection failure after Journal commit is recoverable and cannot erase committed evidence;
- managed-region ownership loss fails closed;
- Reader publication is one-way and recovery-oriented, not a distributed atomic transaction.
