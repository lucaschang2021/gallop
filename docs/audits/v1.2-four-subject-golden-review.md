## One-runtime Golden path

The Golden scenario opens Mathematics, Statistics & Econometrics, Finance, and
CS & AI Tutor sessions through one Runtime Bridge, one append-only Journal and
one replay-derived state. It exercises rigorous proof, simulation/inference,
closed-book derivation and No-Agent Coding task types. All projections use the
isolated integration Vault; no real Vault, Reader, cloud target or learner state
is accessed.

The runtime closes without finalizing the original sessions. Eight days later a
new runtime opens four fresh sessions and restores the correct subject concept,
capability and due retest for each. Source-event checks prove each context is
subject-isolated. The normal path imports no DeepTutor adapter.

## Human authority and assistance

Tutor assessments remain unconfirmed candidate evidence. The added
`evidence_confirmation` event requires `actor: human`, explicit
`HUMAN_ATTESTATION`, and an existing same-subject candidate. It appends a
distinct confirmed Elite Evidence record; the candidate is never rewritten.
Exact retry is idempotent, conflicting reuse remains a Journal conflict, and a
second confirmation identity cannot multiply one human attestation.

The Mathematics path records a level-one hint and an assisted candidate before
a later independent proof. Confirmation preserves the actual assistance on the
first attempt, so it contributes only guided evidence. Proof and derivation
quality structures carry the existing Elite 1.1 eligibility fields instead of
inferring rigor from a generic correctness label.

## Retest and non-regression

Due retests are deterministic advisory context derived from eligible confirmed
evidence at explicit T+7 and T+30 boundaries. They do not mutate the frozen V1
queue. One confirmed independent performance may establish
`PARTIALLY_INDEPENDENT` context, but all four synthetic concepts remain mastery
level 0. No Tutor or projection operation asserts mastery.

The Golden run verifies four original and four fresh sessions, ten evidence
records (candidates plus distinct attestations), generated Obsidian session
notes, exact subject restoration, queue invariance and mastery invariance.

This gate is reproducible implementation evidence, not real learner performance
and not the required multi-day dogfood. Dogfood remains a separate blocked
release prerequisite until Lucas uses the four Tutor surfaces in normal study.
